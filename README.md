# 📊 Sort Dataset Using Pandas

## 📌 Project Overview

This project is part of my **Veda Technology Python / AI-ML task**.

The objective of this task is to understand how to sort datasets using **Python and Pandas**. Different sorting techniques are demonstrated using numerical and categorical columns, including ascending, descending, and multiple-column sorting.

---

## 🎯 Objective

The main objectives of this task are:

- Understand how sorting works in a Pandas DataFrame.
- Sort numerical data in ascending order.
- Sort numerical data in descending order.
- Sort categorical data in ascending and descending order.
- Sort a dataset using multiple columns.
- Understand how sorting helps organize and analyze datasets.
